# 🌙 Magic Celine (매직 셀리느) – Beta

**Magic Celine** 는 마법의 대륙 **세르니아(Cernia)** 를 무대로 펼쳐지는 2D 픽셀아트 RPG입니다.  
플레이어는 땅의 마법사 **카논(Canon)** 또는 물의 마법사 **레인(Rain)** 이 되어,  
마법의 대륙의에서 위대한 마법사를 향한 여정을 떠납니다..

이 저장소는 **Magic Celine 베타 버전 빌드 및 관련 자료**를 위한 공간입니다.

---

## 🎮 게임 특징

- 2D 사이드뷰 **동화풍 픽셀 아트** 배경
- 플레이어블 캐릭터: **카논(땅)** / **레인(물)**
- **레벨 1 ~ 30** 성장, 스탯 및 장비 기반 전투
- **섬록 지역 메인 스토리** & 필드/던전/보스
- 인벤토리, 장비, 상점, 퀘스트 시스템
- **거인 록타스(Roktas)** 보스 전투
- 유저 게시판: **Go + Gin 서버**와 연동된 간단한 온라인 게시판

---

## 🖥️ 시스템 요구 사항 (권장)

- OS: Windows 10 64bit
- CPU: Intel i5 / Ryzen 3 이상
- RAM: 8GB 이상
- GPU: 내장 그래픽 또는 동급 이상
- 저장 공간: 여유 1GB 이상

※ 스펙은 베타 기준 임시 권장이며, 추후 변동될 수 있습니다.

---

## 🚀 실행 방법

1. 릴리즈 탭에서 **최신 베타 빌드 압축 파일**을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. `Magic Celine Beta.exe` 를 실행합니다.
4. 첫 실행 시 **1920×1080 풀스크린**을 기준으로 시작되며,  
   옵션 메뉴에서 해상도 및 볼륨을 변경할 수 있습니다.

---

## ⌨️ 기본 조작

- 이동: 방향키 ← → ↑ ↓
- 점프: `Space`
  - 아래 방향키 + `Space` → 하단 점프
- 공격: `Left Ctrl`
- 상호작용 / 대화: (인게임 안내 또는 옵션 참고)
- 스킬 / 아이템 사용: 퀵슬롯에 등록 후 단축키 사용

※ 키 설정은 옵션에서 일부 변경 가능합니다.

---

## 💾 세이브 데이터

- 현재 버전은 **로컬(PlayerPrefs)** 에 세이브 데이터를 저장합니다.
- 추후 정식 버전에서 서버/데이터베이스 기반 저장으로 확장될 예정입니다.
- 베타 기간 중 패치에 따라 세이브 데이터 호환이 깨질 수 있습니다.
